# SenseTestingAudioMachOne

🎙️ Audio AI Verification Pipeline

This tool analyzes audio and video recordings to detect AI-generated speech. It transcribes audio (like .webm, .mp3, or .mp4 files) using OpenAI's Whisper model, then uses a RoBERTa-based detector to identify whether the transcribed text was generated by AI (like ChatGPT) or written by a human.

🛠️ Requirements

Before you start, you need two things installed on your computer (these are NOT Python libraries):

IF YOU ALREADY HAVE PYTHON INSTALLED, SKIP PAST TO FFmpeg. 

**Python (3.9 or higher):** Download from [python.org](https://python.org). During installation, check the box that says "Add Python to PATH".

**FFmpeg:** A media engine that handles audio and video conversion.
- **Mac:** Open Terminal and run: `brew install ffmpeg`
- **Windows:** Run in PowerShell: `winget install ffmpeg` (or follow [this guide](https://ffmpeg.org/download.html))

After installing FFmpeg, restart your terminal/PowerShell.

🚀 Setup Instructions
Follow these steps in order to get the project running on your machine.

1. Clone the Project
Download this repository as a ZIP file and extract it, or use Git:

Bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
2. Install Python Dependencies

Run the following command in your terminal/command prompt to install all required Python packages:

```bash
pip install -r requirements.txt
```

If `requirements.txt` doesn't exist, install these packages individually:
```bash
pip install pydub openai-whisper transformers torch
```

**What each package does:**
- **pydub:** Converts audio files to .mp3 format
- **openai-whisper:** AI model for transcribing audio to text
- **transformers:** Framework for the AI detection model
- **torch:** Machine learning engine (required by transformers)

🖥️ How to Use
Place your audio file (e.g., recording.webm) into the project folder.

Open your terminal and run:

python AudioConversionPipeline.py your_audio_file.webm

YOU MUST REPLACE your_audio_file.webm with the path to get to the audio file.

**What happens next:**

1. **Audio Conversion:** Your file is converted to .mp3 format.
2. **Transcription:** Whisper transcribes the audio to text (downloads the model on first run ~500MB).
3. **Analysis:** The text is split into 510-token chunks and analyzed by the AI detector.
4. **Results:** You get per-chunk results and an overall verdict (AI-Generated vs. Human-Written).

📂 Project Structure
- **AudioConversionPipeline.py:** Main script that orchestrates the entire pipeline (conversion → transcription → detection)
- **.env:** (Optional) Configuration file for environment variables
- **requirements.txt:** Lists all Python dependencies

💡 Understanding Results

**Fake vs. Real:**
- **Fake:** The detector identified the text as likely AI-generated (ChatGPT, Claude, etc.)
- **Real:** The detector identified the text as likely human-written

**Confidence Score:** Shows how confident the model is in its assessment (0% = uncertain, 100% = very confident)

**Per-Chunk Results:** Long transcripts are analyzed in 510-token chunks. Results show:
- Number of chunks analyzed
- AI-Generated chunk count
- Human-Written chunk count
- Average confidence across all chunks
- Overall verdict based on majority vote

⚠️ Troubleshooting

**"FFmpeg not found":** Restart your terminal after installing FFmpeg. On Windows, close all PowerShell windows.

**Slow first run:** On first use, the script downloads ~500MB of AI models. Subsequent runs are much faster.

**Memory errors:** If your computer is older, reduce memory usage by:
  - Closing other programs
  - Using Whisper's "tiny" model instead of "base" (see code comments)

**Empty transcription:** Ensure your audio file is in a supported format (.webm, .mp3, .mp4, etc.) and contains clear audio.
